# Gouvernance — Unité → Processus → analyses

Vision : le **Processus** devient le centre de gravité de la gouvernance, sans silos GRC.

```
Unité (UNT)
  ├─ Attributions / missions institutionnelles (UniteAttribution)
  ├─ Objectifs stratégiques (OBJ)
  ├─ Collaborateurs (Utilisateur)
  └─ Processus (PRC)
        ├─ RACI (facultatif)
        ├─ Actifs IT (AIT) ← ProcessusActifIT
        ├─ Continuité des activités ← ProcessusContinuité + dépendances Processus
        ├─ Protection des données (léger)
        ├─ Documents (DOC)
        └─ Risques (RSK) → Contrôles SCI (CTL)
```

Vues transversales (consolidation) : Risques, Contrôles, Actifs IT, Documents, Continuité (Roadmap), Inventaire données (Roadmap), **Exigences / Arbitrages / Décisions**, Qualité processus.
